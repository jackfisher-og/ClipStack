## ClipStack V1.0
### The Windows Clipboard reimagined.
This is an open-source repository for the ClipStack desktop app. This app was created to solve a peev of mine where any content that I copied ended up lost by the end of the day. The solution? Create a reliable app where up to 50 entries could be retrieved way in the future after I needed them. I found an API link for an AI endpoint that I needed? It's in there. Lost my API key that I made yesterday? It's in there. The best part is that all entries that are made are stored locally on your machine, no cloud based mess necessary.

### How do you use it?
Once the app is installed using the installer located in the `Output` folder, just launch it. It will run in the background, hidden away in your system tray until you need it again. Copying text and images creates entries that are stored and retrievable through the app. Either click on the app in your start menu or desktop, or use the global `ctrl + alt + v` hotkey to summon it. Scroll through the carousel of entries to find the one that you need, click on it and paste it where you need to.

### Additional notes
Bare in mind that this is a very early development of the app so the overall visual appeal is lacking. However, it's intended functionality works as expected.
